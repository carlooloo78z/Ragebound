# RAGEBOUND

**EVERY FIGHT HAS A LEGEND.**

A browser fighting game with 12 fighters, five martial-arts styles, eight
arenas, five computer difficulties and local two-player matches.

Fight through multiple rounds, earn fictional coins from match results and
crowd support, buy cosmetics, and upgrade your fighter. The game includes
ground/air rolls, training tools and an animated title screen.

## Play and save

The game runs directly in the browser. Use the in-game controls guide for
keyboard and touch controls; Player 2 moves with I/J/K/L.

Guest progress and optional device accounts are saved in the current browser.
There is no online account server or cross-device sync in this GitHub Pages
edition. Use **Account / Power Up > Back Up Save** and **Import Save** to move
progress between browsers or from the original local game. Passwords and saved
player data are never included in this repository.

## GitHub Pages

Publish the public repository's **main** branch from **/(root)** in
**Settings > Pages > Deploy from a branch**. No installation, build command,
API key or custom domain is needed. The empty .nojekyll file publishes the
HTML, CSS and JavaScript directly.

These files are generated by build-pages.cjs in the original project. All
imports and assets use relative paths, so the game works under a project URL.
This edition sets data-hosting="static" to disable local-server API requests.
